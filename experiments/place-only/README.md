# Temporary absolute-place experiment

This is a snapshot of the current R2 sources, with changes generated by
`scripts/prepare_place_experiment.py`. The main checkout's implementation is
unchanged. Geometry is rotation-distinct; position is factored into an absolute
coordinate. The exposed Base has `place(ObjectT, CoordT)`, no `poseOf`, and no
`Translate` signature or evaluator. Existing task abstraction discovery is used
without a seeded translation definition.

From the repository root, recreate the source snapshot with:

```powershell
python scripts/prepare_place_experiment.py
```

From this directory, build and check the experimental language:

```powershell
New-Item -ItemType Directory -Force build/tmp | Out-Null
$env:TEMP=(Resolve-Path build/tmp).Path
$env:TMP=$env:TEMP
ghc -O2 -isrc -iapp -outputdir build -tmpdir build/tmp -o latis-place.exe app/Main.hs
runghc -isrc CheckPlace.hs
```

From the repository root, run the Full protocol and six original ablations:

```powershell
python scripts/run_place_experiment.py --modes Full
python scripts/run_place_ablations.py
python scripts/prepare_place_audit.py
runghc -iexperiments/place-only/src experiments/place-only/ExpressibilityAudit.hs
python scripts/report_place_experiment.py
```

Full results are in `results/place-only`; ablations are in
`results/place-only-ablations/<mode>`. Read `results/place-only/REPORT.md` for
the combined comparison and limitations. `ExpressibilityAudit.hs` contains
post-search reference programs, never solver inputs. Existing old-version
test suites expect the removed primitive and are not claimed compatible.
